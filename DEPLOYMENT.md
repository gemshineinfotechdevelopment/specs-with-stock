# 🚀 VPS Deployment Guide: specs-billing.gemshine.tech

Complete production deployment guide for **LuminaOptic Vision Care POS & Billing** on your VPS.

---

## 📌 Architecture & Specifications

| Component | Setting / Path | Details |
| :--- | :--- | :--- |
| **Domain / Subdomain** | `specs-billing.gemshine.tech` | Points to your VPS Public IP (DNS `A` Record) |
| **Backend Service** | Express.js + Node 20 LTS | Managed via **PM2** on internal port **`5026`** |
| **Frontend Service** | React 19 + Vite + Tailwind CSS | Built to `/dist` and served through **Nginx** |
| **Database** | **MongoDB** (Local VPS or Atlas) | `mongodb://127.0.0.1:27017/specs_billing` |
| **Reverse Proxy** | **Nginx** | Proxies `/api/` to `http://127.0.0.1:5026`, routes `/` to `/dist` |
| **SSL / HTTPS** | Let's Encrypt (**Certbot**) | Auto-renewing free SSL certificate |
| **Process Manager** | **PM2** | Auto-restart on reboot, log rotation, zero-downtime reloads |

---

## ⚡ Step 1: DNS Setup (Before starting VPS setup)

In your Domain DNS provider (Cloudflare, GoDaddy, Namecheap, etc.):
- **Type**: `A`
- **Name / Host**: `specs-billing` (or `specs-billing.gemshine.tech`)
- **Points to / Value**: `<YOUR_VPS_PUBLIC_IP>`
- **TTL**: Auto / 300 seconds

---

## ⚡ Step 2: One-Click Initial VPS Setup

SSH into your VPS as `root` or `sudo` user:
```bash
ssh root@<YOUR_VPS_IP>
```

Run the automated setup script included in this repository:
```bash
# Clone your project or upload project files to /var/www/specs-billing
git clone <YOUR_GIT_REPO_URL> /var/www/specs-billing
cd /var/www/specs-billing

# Make scripts executable
chmod +x setup-vps.sh deploy.sh

# Run the setup script (Installs Node 20, MongoDB, PM2, Nginx, Certbot)
sudo ./setup-vps.sh
```

*(Or follow manual commands below if you prefer executing step-by-step)*

## 🛠️ Manual Step-by-Step VPS Setup (Alternative)

### 1. Update VPS & Install Node.js 20 LTS
```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y curl wget gnupg git ufw software-properties-common ca-certificates lsb-release

# Install Node.js 20 LTS
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
sudo npm install -g pm2
```

### 2. Install & Start MongoDB Community Edition
```bash
# Import MongoDB GPG key
curl -fsSL https://www.mongodb.org/static/pgp/server-7.0.asc | sudo gpg -o /usr/share/keyrings/mongodb-server-7.0.gpg --dearmor --yes

# Add MongoDB APT repository
echo "deb [ arch=amd64,arm64 signed-by=/usr/share/keyrings/mongodb-server-7.0.gpg ] https://repo.mongodb.org/apt/ubuntu jammy/mongodb-org/7.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-7.0.list

# Install MongoDB
sudo apt update
sudo apt install -y mongodb-org

# Start and Enable MongoDB on boot
sudo systemctl daemon-reload
sudo systemctl enable mongod
sudo systemctl start mongod

# Verify MongoDB is running
sudo systemctl status mongod
```

### 3. Setup Project Folder
```bash
sudo mkdir -p /var/www/specs-billing
sudo chown -R $USER:$USER /var/www/specs-billing
cd /var/www/specs-billing
```

### 4. Build & Start with PM2 (Port 5026)
```bash
# Install dependencies
npm install

# Build frontend and compile backend
npm run build:all

# Start with PM2 using ecosystem configuration
pm2 start ecosystem.config.cjs --env production

# Save PM2 process list so it restarts on system reboot
pm2 save
pm2 startup
# (Run the sudo env command generated by pm2 startup if prompted)
```

### 5. Configure Nginx
```bash
# Copy the provided Nginx configuration
sudo cp nginx/specs-billing.gemshine.tech.conf /etc/nginx/sites-available/specs-billing.gemshine.tech.conf

# Enable site
sudo ln -sf /etc/nginx/sites-available/specs-billing.gemshine.tech.conf /etc/nginx/sites-enabled/

# Test Nginx syntax
sudo nginx -t

# Reload Nginx
sudo systemctl reload nginx
```

### 6. Activate SSL Certificate (HTTPS)
```bash
sudo certbot --nginx -d specs-billing.gemshine.tech
```
Select option to redirect all HTTP traffic to HTTPS automatically.

## 🔄 Routine Deployment / Code Updates

Whenever you make changes to the code:
```bash
cd /var/www/specs-billing
git pull origin main
./deploy.sh
```
`./deploy.sh` automatically compiles the frontend, bundles the backend, and reloads PM2 with zero downtime!

## 📋 Useful Production Commands

### Check PM2 Application Status:
```bash
pm2 status
pm2 logs specs-billing-server
pm2 restart specs-billing-server
```

### Check Backend Health:
```bash
curl http://127.0.0.1:5026/api/health
```

### Check MongoDB:
```bash
sudo systemctl status mongod
mongosh --eval "show dbs"
mongosh specs_billing --eval "db.products.countDocuments()"
```

### Check Nginx:
```bash
sudo nginx -t
sudo systemctl status nginx
sudo systemctl reload nginx
sudo tail -f /var/log/nginx/error.log
```
